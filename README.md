# OverUX

**OverUX = UX Oversight.**

OverUX is an independent strategic reference asset exploring the decision layer above interface production: structured pre-release inspection of interface behavior, evidence and unresolved uncertainty.

## Public release v0.1

- `/` — category thesis and conceptual oversight instrument
- `/oversight/` — working definition, boundaries and category language
- `/framework/` — OAF-001 v0.1 research framework
- `/sources/` — source register and evidence classes
- `/acquire/` — qualified strategic acquisition surface

## Production principles

- Static-first, dependency-light, GitHub Pages ready.
- No aggregate UX score.
- No certification or external-standard conformity claims.
- External standards, guidance and emerging research are classified separately.
- The interface embodies the thesis: an inspection plane sits above an interface specimen.
- Accessibility and reduced-motion behavior are part of the implementation, not decorative claims.
