# OverUX Decision Log

## DEC-001 — Semantic fixation: UX Oversight

- **Date:** 2026-08-30
- **Status:** Binding for v0.1 production
- **Decision:** OverUX is positioned as **UX Oversight** — the decision layer above interface production.
- **Rationale:** The name becomes more valuable when it names a category/operating layer rather than a generic UX agency, template or design service. The growth of generative UI makes explicit inspection, evidence and release judgment increasingly salient.
- **Production adjacency:** Governs `/`, `/oversight/`, `/framework/`, site identity and acquisition language in this release.
- **Boundary:** Do not position OverUX as a UI template/framework brand, a standards body, certification authority or generic design agency.
- **Reversal condition:** Only if market/legal diligence shows the category is untenable or a demonstrably stronger, cleaner semantic position emerges.

## DEC-002 — Evidence posture and non-certifying model

- **Date:** 2026-08-30
- **Status:** Binding for v0.1 production
- **Decision:** OAF-001 is explicitly labeled **Research Model v0.1**. Normative standards, professional guidance and emerging research must remain distinguishable. No borrowed authority.
- **Rationale:** Trust comes from preserving source authority and uncertainty, not overstating the model.
- **Production adjacency:** Governs `/framework/`, `/sources/`, `llms.txt`, footer disclaimers and metadata.
- **Reversal condition:** A future formal standards or certification program would require a separate governance decision, evidence base and conformance process.

## DEC-003 — No composite UX score

- **Date:** 2026-08-30
- **Status:** Binding for v0.1 production
- **Decision:** OAF-001 uses six visible review dimensions and four release states: Not assessed, Review, Block, Release. It does not calculate a weighted or aggregate UX score.
- **Rationale:** A single score can conceal blocking findings and unsupported trade-offs between dimensions. v0.1 prioritizes traceable evidence and decision rationale.
- **Production adjacency:** Governs the homepage decision rail and `/framework/`.
- **Reversal condition:** Only after a validated measurement model demonstrates that aggregation is meaningful, reproducible and does not mask blockers.
